# 第一章 Solidity 语法入门

这一章建立后续所有合约开发需要的语言基础。你会从最小可运行合约开始，逐步理解状态如何保存、函数如何改变状态，以及不同数据类型在 EVM 中意味着什么。

## 学习目标

- 编译并理解第一份 Solidity 合约
- 区分值类型、引用类型和常见数据位置
- 正确使用函数可见性、修饰符与返回值
- 用条件、循环和错误处理表达业务约束

## 完成标准

完成本章后，你应该能不依赖模板写出一个小型状态合约，并能解释每个公开函数对链上状态和调用者的影响。
