# 第二章 Foundry 开发环境配置

Solidity 语法只有进入可重复的工程流程才真正有用。本章围绕 Foundry 建立开发环境，把项目初始化、依赖管理、测试、部署和命令行交互串成一条完整链路。

## 学习目标

- 理解 `forge`、`cast`、`anvil` 和 `chisel` 的职责
- 创建结构清晰、依赖可追踪的 Foundry 项目
- 编写单元测试、模糊测试与主网分叉测试
- 在本地链和公开测试网完成部署与交互

## 实践建议

为本章单独创建练习仓库，并提交每一步变化。遇到失败时保留命令、版本与完整错误信息，它们通常比重新安装更能帮助定位问题。
