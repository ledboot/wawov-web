# 第四章 高级特性与安全实践

当合约开始组合多个模块，可维护性和攻击面会同时增长。本章讨论继承、接口与错误处理的工程取舍，并把安全检查放进每一次外部调用和状态更新中。

## 学习目标

- 选择组合、接口或继承来组织合约能力
- 使用自定义错误降低 Gas，同时保留清晰失败语义
- 识别重入、访问控制、价格操纵等常见风险
- 用 Checks-Effects-Interactions 等模式缩小攻击面

## 阅读方式

不要只记住漏洞名称。对每一种风险都尝试回答：攻击者控制什么输入、状态在哪一步失真，以及测试如何证明修复有效。
