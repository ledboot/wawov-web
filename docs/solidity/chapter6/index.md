# 第六章 部署与维护

部署不是执行一条命令，而是把代码、配置、权限和验证结果一起交付。本章关注多链环境下的配置隔离、确定性部署和升级流程，避免测试网成功掩盖生产风险。

## 学习目标

- 为不同链管理 RPC、账户、地址和验证配置
- 使用脚本实现可重复部署，并记录部署产物
- 理解 Transparent、UUPS 与 Beacon 等升级模式
- 为升级建立提案、模拟、执行和回滚步骤

## 上线前证据

保留提交哈希、编译器配置、部署交易、合约地址、验证链接和权限移交记录。任何无法追踪到源码的生产地址，都应被视为运维风险。
