这套教程面向希望真正完成智能合约开发、测试和上线的人。内容从第一份合约开始，逐步进入权限、存储、Gas、安全、部署与生产运维；每一阶段都尽量用可以运行和验证的工程实践来解释概念。

## 你会获得什么

- 独立使用 Foundry 创建、测试和部署 Solidity 项目
- 理解常见代币、NFT 与 AMM 合约的核心设计
- 用测试复现典型攻击，并验证修复是否有效
- 建立审计、性能回归和生产发布的基本流程

## 学习路线

本教程将从零开始，循序渐进地带领你学习 Solidity 智能合约开发。以下是完整的学习路线：

1. **第一章：Solidity 语法入门**
   - 基础语法和数据类型
   - 函数和修饰器
   - 控制结构和异常处理

2. **第二章：Foundry 开发环境配置**
   - Foundry 核心工具链
   - 安装与初始化项目
   - 编写与编译合约
   - 自动化测试实践
   - 部署与交互

3. **第三章：合约核心概念**
   - 状态变量与存储机制
   - 权限控制与修饰器
   - 事件与日志

4. **第四章：高级特性与安全实践**
   - 继承与接口设计
   - 错误处理与 Gas 优化
   - 安全漏洞防范

5. **第五章：实战项目开发**
   - ERC20 代币合约
   - NFT 合约
   - DEX 合约

6. **第六章：部署与维护**
   - 多链部署策略
   - 合约升级模式

7. **第七章：性能优化与工程实践**
   - Gas 成本模型与度量方法
   - 存储与计算优化实战
   - 性能 CI 与回归防线

8. **第八章：安全与上线工程化**
   - 攻击复现与防御实战
   - 审计流程与检查清单
   - 生产发布 Runbook 与应急响应

## 学习建议

1. **按顺序完成前两章：** 先建立语言和工具链基础，避免只看语法却无法运行项目。
2. **所有代码都亲手执行：** 修改示例、制造失败，再观察测试和交易结果。
3. **把安全放进开发过程：** 不要等合约写完才检查权限、外部调用和边界条件。
4. **记录环境与版本：** 链、编译器和依赖差异经常是问题的一部分。
