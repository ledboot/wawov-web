# 第三章 合约核心概念

这一章从“代码能运行”进入“状态是否可靠”。状态变量、权限边界和事件设计决定了合约能否被安全调用、正确索引，并在出现问题时提供足够证据。

## 学习目标

- 理解 storage、memory 与 calldata 的使用边界
- 设计最小权限模型，避免关键操作被错误暴露
- 使用 modifier 表达可复用的调用前置条件
- 设计可被链下服务稳定消费的事件与索引字段

## 完成标准

完成本章后，你应该能画出合约的角色与权限关系，解释关键状态所在的数据位置，并为每一次重要状态变化设计清晰事件。
